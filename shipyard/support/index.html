Signing in (iPhone)

How does sign-in work?

  1. Tap Sign In with GitHub. Shipyard shows a short code.
  2. Tap Copy Code and Open GitHub, paste the code, and approve. Or, on any other device, go to github.com/login/device and type the code there.
  3. Come back to Shipyard. It finishes on its own.

Your iPhone gets its own access, separate from Shipyard for Mac, so you can revoke one without affecting the other.

The code expired

Codes last about 15 minutes. Tap Try Again for a new one.

Why does GitHub ask for access to my repositories?

GitHub has no read-only option for private repositories' checks, so the request covers full repository access. Shipyard only ever reads pull requests and their checks. It never changes anything.

Missing pull requests

PRs from my work organization don't show up

There are two usual reasons:

  • Single sign-on. If the organization uses SAML single sign-on, Shipyard shows a banner with an Authorize on GitHub button. Authorize once, then pull to refresh.
  • Third-party app restrictions. The organization may restrict third-party apps.
    • Go to GitHub › Settings › Applications › Authorized OAuth Apps › Shipyard and request access for that organization.
    • An organization owner then needs to approve it.

Which PRs does Shipyard show?

  • By default, open pull requests you authored, in any repository.
  • Turn on Include PRs assigned to me in Settings to add the ones assigned to you.

The Live Activity (iPhone)

It doesn't appear during my work hours

  • Check that work hours are on in Shipyard › Settings, with the right days and times.
  • Make sure Live Activities are allowed: iPhone Settings › Shipyard › Live Activities.
  • If you swiped it away, it stays hidden until your next workday. To bring it back now, tap Show Now on Shipyard's home screen.
  • Shipyard schedules the next few workdays ahead whenever it runs. If you haven't opened it in a while, open it once.

How up to date are the numbers?

  • Tap ↻ on the Live Activity for an instant refresh.
  • Otherwise it updates whenever iOS gives Shipyard background time. That's usually every 15 minutes or so, but iOS decides.
  • If the data is more than 30 minutes old, the Live Activity says so.

It ended before my workday did

iOS ends every Live Activity after 8 hours. Open Shipyard and tap Show Now to start a fresh one.

Can I use it on iPad?

Yes. Your pull requests and checks work the same way. Live Activities only exist on iPhone, so the work-hours feature is hidden on iPad.

Shipyard for Mac

  • The Mac app lives in your menu bar and signs in with the GitHub CLI.
  • To install it, see the Shipyard page.
  • It updates itself. You can also choose Check for Updates… from its menu.

Signing out and privacy

  • Sign Out in Settings removes your token and cached data from the device.
  • Shipyard collects nothing. See the privacy policy.
